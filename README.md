# 叠叠乐 · 小瑞安侬与尘酿鹰

基于《重返未来：1999》的角色**小瑞安侬**与她的伙伴**尘酿鹰**做的一个小游戏：尘酿鹰一只只落在她头顶。

## 在线游玩

`https://<你的用户名>.github.io/<仓库名>/`

打开就能玩，无需下载安装。

## 玩法

- 尘酿鹰在画面上方左右游荡，**点击画面或按空格**让它落下。

## 特性

- **单文件游戏**：立绘、音效、BGM、插图全部以 base64 内嵌在 `叠叠乐.html` 里，双击即可离线玩。
- 无依赖、无构建，纯 HTML + Canvas。
- 支持鼠标与触屏；右下角可开关音效（BGM 与小黄鸭音效一并控制）。

## 目录

```
index.html            一键入口（预取游戏并自动进入）
叠叠乐.html           游戏本体，单文件含全部素材
```

## 本地游玩

直接用浏览器打开 `叠叠乐.html`；或起一个本地静态服务（推荐）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/
```
